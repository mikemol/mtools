# stubtest allowlist for the panflute stub.
#
# ⚑⚑⚑ EVERY ENTRY IS A CONSTRUCTOR, AND THAT IS THE WHOLE ADMISSIBLE SHAPE. mdstruct NEVER
# constructs a panflute element — it reads them, via isinstance checks and attribute access, from
# whatever `load` returns. So each `__init__` here is surface the stub declines to model rather
# than a divergence it is hiding, and an entry that is NOT a constructor is a real inconsistency
# in something this package calls.
#
# ⚑⚑ THE GENERATED ALLOWLIST WAS NOT USABLE AS GENERATED, AND THAT IS THE MEASUREMENT. Running
# `--generate-allowlist` produced 15 entries, and two of them were `panflute.load` and
# `panflute.stringify` — the two functions mdstruct calls most. Both were REAL defects: the stub
# named `load`'s parameter `source` when the runtime calls it `input_stream`, and omitted
# `stringify`'s `newlines` entirely. Accepting the generated file would have frozen both as
# permanently allowed and made the gate vacuous at exactly the point it exists to check. They are
# fixed in the stub; this list carries what remains.
#
# ⚑⚑ A BOUND ON WHAT THIS GATE CAN SEE, MEASURED BY F-ARM: stubtest checks SIGNATURES, not
# RETURN TYPES. Declaring `stringify` as returning `int` passes silently, because the runtime
# function carries no annotation to disagree with. Two of three deliberate corruptions fire — a
# wrong parameter list and a wrong parameter name — and the third does not. Return types are
# covered by mypy against the CALL SITES instead, which is a different instrument answering a
# different question, and saying so here is the difference between a gate with a known edge and
# one believed to be total.
#
# ⚑ REGENERATE BY HAND, NEVER BY PIPE. `--generate-allowlist > this-file` silently launders a new
# divergence into an allowance, which is the same laundering `--init-absent` refuses on a second
# run. A new entry must be read and argued before it lands.
#
# ⚑ W1953 (2026-10-25): 18 OF THE 19 ENTRIES ARE PAID DOWN. Each constructor but one, and the two
# non-constructor entries `Element.walk` (the stub lacked `stop_if`) and `Element.__new__`, is
# modelled in the stub from `inspect.signature` of the installed library; stubtest then reported
# those entries unused and nothing else.
#
# ⚑ THE ONE LEFT IS COUNTED DEBT, NOT A WAIVER. `Doc.__init__` takes a keyword-only `format`, which
# shadows the builtin; declaring it in the stub makes the lint ratchet refuse a new key, and the
# way round that (a per-file exemption in pyproject) would move the debt out of a file the census
# counts into one it does not, which reads as paydown while the debt merely moved (operator,
# host line 97317). It stays here, read by the ratchet, until a real fix exists.
