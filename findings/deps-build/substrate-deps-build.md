## SB-04 — Hermeticity (§Q-4)

**What the build reaches without declaring:** every implicit dependency in SB-02.

⚑ **The gate that passes by not running — measured, and it is live.**
`scripts/check_scratch_runtime.py` opens with an `import cupy` probe and, on ImportError, prints
`SKIPPED (no cupy/GPU)` and **exits 0**. It is a declared Phase A gate that **always passed without
executing**, so its whole coverage property was unit-proven and never observed in situ.

> *"A GATE THAT SELF-SKIPS TO EXIT 0 IS WORSE THAN A RED ONE: the roster counts it green, and
> non-execution is indistinguishable from a clean pass."*

**Class: citation** (`pyproject.toml`, verbatim).

⚑⚑ **And a second hermeticity class substrate already paid for.** `substrate/type_gate.py` records
that under `uv run --with mypy`, a bare `python3` subprocess is a *different interpreter* — mypy
existed for one and not the other, the run failed, the parse found no error lines, and **zero keys
was banked as clean**. Same root cause as a non-hermetic wheel action: uv's environment is an
undeclared input.

## SB-05 — Build design (§Q-5)

**Two builds, and they are unrelated.**

The **Agda** build is one flat import-DAG makefile (`agda/Flat.mk`, generated) over ~3.5k modules.
Each target is the real `.agdai`, depending on its own source and every direct import's `.agdai`.
`make -j` self-throttles by RAM: the agda shim routes every compile through `membudget run`, which
leases from a machine-global budget and **blocks** rather than failing when the budget cannot cover
it. Per-module GHC heap is capped, and exceeding it is a **build failure** — a forcing function to
seal heavy neutrals `opaque` rather than grow the cap.

The **Python** side has no build graph at all. There is no bazel workspace and no bazel in the
checkout. `substrate/bazel_emit.py` emits `agda_module(...)` calls loading a `//bazel:agda.bzl`
**that does not exist**, and the module says so. ⚑ **Whether the emitted text builds is UNMEASURED.**

**Caching:** the Agda build caches on `.agdai` mtime. Nothing else caches. **Remote execution: none
— substrate is not on `--config=remote`**, which per `§X` is a finding rather than an error.

## SB-06 — Test design (§Q-6)

A test is an **arm**: `def <name>(out: list[str]) -> int`, appending failure messages and returning
a count. Suites hold a declared `_ARMS` roster.

    run_selftests --list --quiet   ->  409 suite(s)
    arm_shape                      ->  1909 arms across 189 suites
    arm_claims                     ->  1277 one-claim · 616 several · 11 silent · 5 UNDECIDED

⚑ **Arm names are already claim-shaped prose** — `a_step_that_refuses_propagates_rather_than_being_swallowed`,
`an_unknown_target_is_refused_by_name`. Each names one falsifiable fact.

**Is a test proven falsifiable?** ⚑ **Partly, and the honest answer is a three-way split.** The
warrant ledgers carry a `check` per claim with declared kinds, and the ledger's own census reports
`standing` as *"⚑ VACUOUS — passes unconditionally"*. Registration now **probes polarity**: a
`refuses:` witness whose command exits 0 today is refused at filing, because it would be born
reporting the opposite of its own finding. But **`standing` witnesses remain unfalsifiable by
construction**, and they are the largest kind.

**Class: citation** (`findings.py --kinds`, verbatim label).

## SB-07 — Gate design (§Q-7)

    gate_population --gates    ->  18 gates
    gate_census --baselines    ->  19 ratchets: 7 ok · 11 EMPTY · 0 ABSENT · 1 UNREAD

Three layers: **pre-commit** (~37 declared gates, two phases, `core.hooksPath` wired), **Claude
PreToolUse hooks** (four, all armed to refuse — structural-query, no-chaining, shellcheck, pycheck),
and **per-file zero-tolerance** (ruff `select=ALL` + mypy strict with `disallow_any_expr`).

⚑ **EMPTY is the STRONGEST setting, not a defect** — the empty set as baseline means every offender
is a new key and nothing is grandfathered. ⚑⚑ **And ABSENT would be the opposite**: a ratchet with
no baseline takes the record-and-pass branch and **exits 0 regardless of what it measured**. Zero
ABSENT today. **UNREAD is a fact about the reader, not a verdict about the gate** — three states,
kept apart deliberately.

**Has it fired?** Yes, repeatedly, and on me. The per-file gate refused a deliberately-defective
probe file this session (the file was never created). The hooks refused ~a dozen commands. The
polarity probe refused two of my own filings.

⚑ **But the commit gate has not passed in a long time.** `commit_refusal` reports **9 would refuse,
28 UNMEASURABLE, 0 measured-green** over 301 staged paths. The 28 are mostly *"writes on a bare
run"* — the reader declining to execute a gate that would mutate. **No verdict, not clean.**
